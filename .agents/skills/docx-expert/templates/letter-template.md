# Business Letter Template — Document Structure

## Layout

```
+----------------------------------------------------------+
|  [Company Logo]                                           |
|  Company Name                                             |
|  123 Business Street                                      |
|  City, State 12345                                        |
|  (555) 123-4567 | info@company.com                       |
|  -----------------------------------------------         |
|                                                           |
|  March 3, 2026                                            |
|                                                           |
|  Mr./Ms. Recipient Name                                   |
|  Title                                                    |
|  Organization Name                                        |
|  456 Recipient Street                                     |
|  City, State 67890                                        |
|                                                           |
|  RE: Subject of the Letter                                |
|                                                           |
|  Dear Mr./Ms. Last Name,                                  |
|                                                           |
|  Opening paragraph — state the purpose clearly.           |
|                                                           |
|  Body paragraphs — provide details, supporting            |
|  information, and context.                                |
|                                                           |
|  Closing paragraph — summarize, state next steps          |
|  or call to action.                                       |
|                                                           |
|  Sincerely,                                               |
|                                                           |
|  [Signature space — 4 blank lines]                        |
|                                                           |
|  Full Name                                                |
|  Title                                                    |
|                                                           |
|  Enclosures: (if applicable)                              |
|  CC: Name (if applicable)                                 |
+----------------------------------------------------------+
```

## Implementation Notes

1. **Letterhead**: Company info in header, 10pt, muted color
2. **Date**: Full format (March 3, 2026), 12pt
3. **Recipient block**: Left-aligned, no indent
4. **RE line**: Bold
5. **Body**: Justified, Calibri 11pt, 1.15 line spacing
6. **Signature space**: 4 empty paragraphs between closing and name
7. **Margins**: 1 inch all sides
8. **No footer** on letters (page numbers only if multi-page)
